# Windows 系统维护工具包（进系统版）

一套在**已装好的 Windows 桌面里运行**的 PowerShell 维护工具，支持 **Windows 7 到 Windows 11**（Windows PowerShell 2.0 – 5.1）。

## 与 PE 版的分工

| 场景 | 用什么 |
| --- | --- |
| 系统进不去、蓝屏、引导坏了 | U 盘 PE 版：离线急救（离线清理、修复引导、备份数据） |
| 系统能正常进桌面 | **本工具包**：硬件检查、系统健康报告、在线清理与修复 |

简单说：PE 负责「救活」，本工具包负责「体检 + 保养」。

## 使用方法

1. 把整个 `ps-toolkit` 文件夹拷到目标电脑任意位置（桌面、D 盘、U 盘都行，不要放在系统临时目录）。
2. 双击 **`启动维护.cmd`**。
3. 弹出管理员权限请求时选「是」（脚本会自动提权；已是管理员则直接进入）。
4. 在菜单里输入编号选择功能，跑完按回车返回菜单，`0` 退出。

也可以单独运行某个模块脚本（需先以管理员身份打开 PowerShell），但推荐统一从菜单进。

运行产生的报告/日志会保存在同目录的 `reports\` 文件夹（首次运行自动创建）。

## 功能说明

### 1. 硬件检查（Check-Hardware.ps1）
- CPU 型号/核心数、内存总量与每条内存的插槽/容量/频率
- 物理硬盘型号/容量/介质类型/健康状态（Win8 以上用 Get-PhysicalDisk；Win7 自动回退 WMI 并注明）
- 各磁盘卷总容量/剩余空间
- 笔记本电池：设计容量、满充容量、健康度百分比（机型不提供数据时如实标注）
- 主板与 BIOS 版本信息
- 报告保存为 `reports\hardware-<时间>.txt`

### 2. 系统健康报告（Check-System.ps1）
- 系统版本、安装日期、最近开机时间、已连续运行时长
- 最近 7 天系统日志里的严重/错误数量与前 10 条摘要；应用程序日志错误数
- Windows 更新：历史记录总数与最近几条更新的结果（成功/失败）
- 安全软件：Security Center 注册的杀毒软件与 Defender 服务状态
- 待重启标志（更新/CBS 是否要求重启）
- 报告保存为 `reports\system-<时间>.txt`

### 3. 一键清理（Clean-System.ps1）
白名单范围（写死在脚本里，不接受外部改路径）：
- 当前用户临时文件、系统临时文件
- Windows Update 下载缓存（清理时短暂停用 wuauserv/bits，清完自动恢复）
- 回收站（全部固定磁盘）
- 缩略图/图标缓存
- 传递优化文件（有则清）

流程：**先统计每项可清理大小 → 展示清单 → 输入 Y 确认后才真删** → 逐项报告实际释放量（被占用的文件自动跳过并计入「剩余」）。
记录保存为 `reports\clean-<时间>.txt`。

### 4. 系统修复（Repair-System.ps1）
依次执行，每步记录退出码与结论：
1. `sfc /scannow` 系统文件检查，并尝试摘录 CBS 日志结论
2. `DISM /Online /Cleanup-Image /RestoreHealth` 组件存储修复（**仅 Win8 以上**）
3. `chkdsk` 系统盘**只读**扫描；发现错误只报告，询问后才可安排下次开机修复

记录保存为 `reports\repair-<时间>.txt`。整个过程可能需要数十分钟。

### 5. 自启项管理（Manage-Startup.ps1）
- 列出来源三处：注册表 Run/RunOnce（HKLM/HKCU，含 32 位视图）、启动文件夹（当前用户/所有用户）、计划任务中的登录触发项
- **默认只列出，不动任何项**
- 禁用时先备份：注册表项导出为 `.reg`、启动文件移入备份目录、计划任务置为禁用，清单写入 `reports\startup-backup-<时间>\manifest.txt`
- 恢复：选 R 并挑一个备份目录，即按清单还原（导入 .reg、移回文件、重新启用任务）

## 安全边界

- **不联网、不下载任何东西、不调用第三方工具**，全部使用 Windows 自带组件。
- **不做注册表清理、不关 Windows Defender、不关系统更新**，不用任何「优化偏方」。
- 清理只删白名单内的临时/缓存文件，**绝不碰** pagefile.sys、hiberfil.sys、用户文档、浏览器书签/密码等数据。
- 所有会改动系统的动作（清理实删、禁用自启、安排 chkdsk 开机修复）都先说明、等确认，并留日志或备份，可回滚。
- 每个脚本启动时自检管理员权限，非管理员直接提示退出。

## Win7 注意事项

- Win7 自带 PowerShell 2.0，本工具包按 PS 2.0 语法基线编写，可直接运行；`启动维护.cmd` 会以 `-ExecutionPolicy Bypass` 启动，无需改系统执行策略。
- Win7 的 DISM **没有** `/RestoreHealth` 能力：系统修复第 2 步会自动跳过并提示改用微软官方「系统更新准备工具（System Update Readiness Tool / CheckSUR）」——需从微软官网手动下载对应版本运行（本工具包不代下载），其日志在 `%windir%\Logs\CBS\CheckSUR.log`。
- Win7 无 Get-PhysicalDisk：硬件检查会回退到 WMI 读取硬盘信息，报告里会注明；WMI 不能可靠区分 SSD/HDD，请以硬盘型号自行判断介质。
- Win7 的事件「严重」级别在经典日志中多以「错误」级别记录，系统健康报告的回退路径按「错误」统计并注明。

## 已知限制

- 本工具包未在全部 Win7–Win11 机型上实测过；首次使用建议先在一台测试机跑一遍「硬件检查/系统健康报告」（纯只读），确认输出正常后再用清理/修复功能。
- 安全软件状态码来自 Security Center 的 productState 原始值，仅供参考，实际防护状态以厂商控制台为准。
- 电池健康度依赖厂商是否通过 WMI 提供设计/满充容量，部分机型读不到时会明确标注「不可用」，不会给假数字。
- 缩略图/图标缓存中被资源管理器锁定的文件删不掉属正常现象，清理报告会如实显示剩余量；重启后通常可清。
- chkdsk 只读模式对系统盘的个别错误提示可能是误报，是否安排开机修复由使用者确认决定。

## 文件清单

| 文件 | 作用 |
| --- | --- |
| `启动维护.cmd` | 双击入口：自动提权 + 绕过执行策略 + 打开主菜单 |
| `Maintenance.ps1` | 主菜单（数字选择 1–6，0 退出） |
| `Check-Hardware.ps1` | 硬件检查 |
| `Check-System.ps1` | 系统健康报告 |
| `Clean-System.ps1` | 一键清理（先统计后确认） |
| `Repair-System.ps1` | 系统修复（sfc / DISM / chkdsk） |
| `Manage-Startup.ps1` | 自启项管理（备份/禁用/恢复） |
| `reports\` | 报告与备份目录（自动生成） |

编码说明：`.ps1` 均为 UTF-8 with BOM 保存，保证中文 Windows 的 PowerShell 5.1 不乱码；`.cmd` 为 UTF-8 并在开头执行 `chcp 65001`。
